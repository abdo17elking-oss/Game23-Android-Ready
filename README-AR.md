# Game23 — نسخة Android جاهزة للبناء

## رفع المشروع على GitHub
ارفع محتويات هذا المجلد كاملة إلى مستودع GitHub جديد، وليس ملف ZIP داخل مستودع فارغ.

## ملفات GLB
ضع أي ملفات GLB داخل:
`app/src/main/assets/`

النسخة الحالية تحتوي بالفعل على:
- `Home.glb`
- `Man.glb`

إذا أضفت ملفًا جديدًا، ارفع الملف في نفس المجلد ثم استخدم اسمه داخل HTML مثل:
`./MyModel.glb`

## بناء APK عبر GitHub Actions
1. ارفع جميع الملفات والمجلدات كما هي.
2. أنشئ الملف:
`.github/workflows/build-apk.yml`
3. انسخ كود Workflow الموجود في الملف المرفق `build-apk.yml`.
4. افتح تبويب Actions وانتظر انتهاء البناء.
5. من صفحة التشغيل الناجح افتح Artifacts ثم نزّل `Game23-debug-APK`.

ملاحظة: اللعبة تستخدم Three.js addons من CDN، لذلك يلزم اتصال إنترنت أثناء تشغيل بعض أجزاء Three.js داخل التطبيق.
